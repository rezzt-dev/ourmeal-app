# OURMEAL APP

## DESCRIPTION

ourmeal is an application developed in kotlin to facilitate the tracking and planning of meals and dinners, as well as creating and exporting customized shopping lists. its goal is to help users organize their daily meals and simplify the management of their shopping.

## FEATURES

- detailed tracking of meals and dinners.
- creation and management of shopping lists.
- exporting lists for printing or mobile use.
- intuitive and easy-to-use interface.

## TECHNOLOGIES

- kotlin (100%)

## INSTALLATION

to run this application locally, follow these steps:

1. clone the repository:  
   `git clone https://github.com/rezzt-dev/ourmeal-app.git`
2. open the project in your preferred ide (for example, android studio).
3. build and run the app on an emulator or a physical device with kotlin support.

## USAGE

after installing the app, you can:

- add and edit daily meals.
- create shopping lists based on the needed ingredients.
- export the list for use during shopping.
